# Himani Sharma — Portfolio

A modern, highly visual, **mobile-first** redesign of Himani Sharma's product
design portfolio.

## What's inside
- **`index.html`** — single-page site (Hero · Work · About · Contact)
- **`css/styles.css`** — mobile-first responsive styling, dark editorial theme
- **`js/main.js`** — scroll reveals, count-up stats, sticky nav, mobile menu

## Design direction
- Bold display typography with generous whitespace (less text, more impact)
- Animated gradient "aura" hero, marquee, and CSS-art project tiles (no image assets required)
- Reveal-on-scroll animations with `prefers-reduced-motion` support
- Fully responsive from 320px up; progressive enhancement (works without JS)

## Run locally
Just open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```

No build step, no dependencies.
